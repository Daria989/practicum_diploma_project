# Яндекс Самокат
Cервис, который позволяет арендовать электрический самокат на несколько дней. У сервиса есть веб-приложение, мобильное приложение и API. В веб-приложении пользователь может оформить заказ на самокат и посмотреть статус доставки курьером.

В репозитории описаны тесты на проверку, что по треку заказа можно получить данные о заказе.
- Для запуска тестов должны быть установлены пакеты pytest и requests
- Запуск всех тестов выполняется командой pytest
